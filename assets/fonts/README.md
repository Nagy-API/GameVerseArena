# Inter fonts

This directory contains the two font files used by the GameVerseArena graphical shell:

- `Inter-Regular.ttf`
- `Inter-SemiBold.ttf`

They are unmodified files from the official [Inter 4.1 release](https://github.com/rsms/inter/releases/tag/v4.1), published by the Inter Project Authors. Inter is distributed under the SIL Open Font License 1.1; the complete license is in `LICENSE.txt` beside the font files.
